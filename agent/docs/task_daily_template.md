# 子代理任务书模板（通用模板）

派活分两轮，两轮都要**写死三条**：先落盘再深挖（读完先写一版）、每约 5 分钟增量回写、总预算 15 分钟。

**第一轮**：数据获取 + 初提 + 主稿候选。
**第二轮**：知识库回写 + 证据层 + 自检 + 待核对清单。

任务书里必须给：输入在哪、产出文件的确切路径（一个）、验收判据、预算、以及"看不到来源就如实说，不许编"。
具体的输入路径、产出目录、真人样本都在私人文件夹里，不在这个包里。
