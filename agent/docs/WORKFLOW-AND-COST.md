# 一轮怎么走 / 成本怎么量（通用模板）

一轮 = 取数 → 初提 → 归类成稿 → 回写面板 → 镜像与知识库回写 → 自检 → 交付并等确认。

- 每轮结束写一行状态（做到哪、卡在哪），别凭印象说"今天做过了"；
- 成本按**事件时间**归档、按 provider 计价；免费线路与付费线路分开看；
- 用量与费用明细属于部署方私人数据，写在私人文件夹里，不进这个包。
