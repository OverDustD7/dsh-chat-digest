# 取数与提炼的经验（通用模板）

- 先读来源、再动手；来源为空就如实回报，**不要编造条目**；
- 链接与附件要落地验证过再写进条目；
- 提炼时的反例库、真实样本、群/来源清单都在私人文件夹里，按它们校准；
- 一次纠正就落成一条规则，写进私人文件夹的知识库（不是写进这个包）。

这里只放"换了部署方也成立"的通则；带具体人/群/校的样本一律放私人文件夹。
