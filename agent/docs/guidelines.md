# 摘要原则

1. 只写有原始证据支持、对使用者有用的信息。未核实的转述要标明来源语气。
2. 本人需要行动的事项优先：动作、期限、入口、附件与限制条件逐一核对。
3. 同一事件跨群、跨天出现时合并；保留新增事实，不重复堆条目。
4. 数字先判断是日期、题号、金额、人数还是编号；不要凭相邻文字猜测含义。
5. 图片先核对前后消息与归属，再判断图片中的文字是否构成使用者的待办。
6. 没有来源就报告没有来源；缺附件就标注缺失，不生成不可打开的链接。
7. 只将必要结论放在面板正文；原文、排障和审计记录留在私人 profile。
8. 自动轮不等待交互提问。拿不准的事记录为待确认并继续可确定的部分。
