# 面板条目格式

面板是持续增长的列表，分为待办、机会与招募、有用信息。每条条目有稳定 `id`、`text`、`kind`、`urgency`、`done`、`src`、`date`、`isNew`。`text` 第一行是一句话结论；后续只展开实际存在的期限、入口、条件、风险、附件与链接。不要为了填模板捏造小节。

`kind` 的通用取值：`todo`、`chance`、`official`、`peer`、`resource`、`life`。`urgency` 的通用取值：`today`、`week`、`later`。同学或群里的经验应标明是个人经验，不能写成官方规定。

面板正文不放原始聊天、大段隐私或内部处理过程。文件链接只指向已确认存在且在允许根内的文件；重要图片按需内嵌。用户勾选的 `done` 状态是用户输入，增量更新必须保留。新一轮清除旧 `isNew` 时，不要误清同一轮刚添加的条目。写入后回读核对数量、id 与状态。
