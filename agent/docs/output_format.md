# 产出形态（通用模板）

**不再每天产出一份独立 md。** 产出是**一份持续增长的列表**：
- 每条 ＝ 一句话总结（第一行）+ 空行 + 正文；正文按信息量定，**不套模板**；
- 目录/来源/期限/联系人/门槛这些要素，有就写、没有的节一个都不写；
- 正文里的**加粗**、http 链接、`[名字](file:相对路径)`、`![说明](img:相对路径)` 都会渲染；
- 回写走插件的 HTTP 接口（整表或按 id 打补丁）。

**只留对人有用的东西**：要他做的动作、能报名/申请的机会、他以后用得上的信息。
过期的动作型信息不进主稿（留档到私人文件夹里的 archive）。

部署方自己的写法与样本放在私人文件夹的 `docs/output_format.md`。
